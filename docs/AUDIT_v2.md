# Аудит v2: система публикации контента «одной кнопкой»

Дата: 2026-10-08. Заменяет MVP и архитектуру из [`AUDIT.md`](AUDIT.md). Факты о соцсетях (раздел 1 в `AUDIT.md`) остаются в силе; здесь добавлены только новые факты.

**Новая цель:** убрать ручную публикацию. Генерация AI-видео не нужна.

**Приоритеты:** 1) автопубликация → 2) минимум ручных действий → 3) описание → 4) хэштеги → 5) озвучка → 6) простая обработка изображения → 7) остальные AI-функции.

## 0. Аудит предыдущего MVP: что убираем

| Было в v1 | Решение | Почему |
|---|---|---|

| Remotion (рендер на React) | ❌ **убрать** | для «картинка + голос» достаточно одной команды FFmpeg |

| Forced Alignment / STT для субтитров | ❌ убрать из MVP | субтитры в MVP не нужны; позже — из таймкодов TTS |
| Многоэкранный веб-интерфейс на Next.js | ⬇️ **заменить на Telegram-бота** | 10–20 секунд с телефона реальны только в мессенджере (см. раздел 8) |
| Gemini Image | ⬇️ **только для сценария №2** | в сценарии №1 картинка уже готова |

## 1. Новая архитектура

```
ВЫ (телефон / ПК)
  │  отправляете картинку (+ необязательно: референс, подпись-задание)
  ▼
TELEGRAM-БОТ (личный, отвечает только на ваш user_id)  ← основной интерфейс
  │
  ▼
BACKEND (один сервис на одном VPS: Python, aiogram + FFmpeg + SQLite)
  │
  ├─ 1. Нормализация картинки (Pillow, бесплатно): EXIF-поворот, JPEG, размеры
  ├─ 2. [только сценарий №2] Gemini Image: «исходник в стиле референса»
  ├─ 3. CLAUDE: один запрос, картинка + профиль проекта («Зазеркалье») →
  │      JSON: тема, текст озвучки, тексты и хэштеги ОТДЕЛЬНО для IG / TikTok / TG / YT,
  │      заголовок YouTube, рекомендация формата для каждой площадки
  ├─ 4. TTS (ElevenLabs): озвучка → mp3
  ├─ 5. FFmpeg: видеообёртка 1080×1920 (картинка + размытый фон + лёгкий zoom + голос)
  │      — только для площадок, где нужно видео
  ├─ 6. Загрузка медиа в R2 → публичные URL (нужны Instagram и TikTok)
  ▼
ПРЕДПРОСМОТР в боте: картинка, голосовое, 4 текста, площадки
  [✅ Опубликовать везде] [✏️ Текст] [🎙 Другой голос] [🔁 Заново] [❌]
  ▼
PUBLISHER — отдельная задача на каждую площадку, ошибка одной не мешает остальным
  ├─ Instagram Graph API
  ├─ TikTok Content Posting API
  ├─ Telegram Bot API (тот же бот — админ вашего канала)
  └─ YouTube Data API
  ▼
ЖУРНАЛ (SQLite) + итоговое сообщение в боте со ссылками на посты
```

**Почему Telegram-бот, а не веб-приложение.** Отправить фото боту — 3 секунды, нажать кнопку — 1 секунда. Не нужно открывать сайт, логиниться и ждать загрузки страницы. Telegram сам даёт интерфейс, уведомления, хранение истории и работу с телефона. Веб-страница остаётся опцией для версии 2 (журнал, настройки, подключение аккаунтов). OAuth-подключение площадок всё равно идёт через браузер — по ссылке из бота, один раз.

**Почему Python.** Без Remotion больше нет причины держать TypeScript. У Python есть зрелые библиотеки для всех частей: `aiogram` (бот), официальные SDK `anthropic`, `elevenlabs`, `google-genai`, `google-api-python-client` (YouTube), Pillow, FFmpeg.

## 2. Какие API реально нужны

| # | API | Зачем | Обязателен? |
|---|---|---|---|
| 1 | **Anthropic API (Claude)** | анализ картинки, все тексты и хэштеги | да |
| 2 | **ElevenLabs API** (или OpenAI TTS как бюджетный вариант) | озвучка | да |
| 3 | **Telegram Bot API** | интерфейс + публикация в канал | да |
| 4 | **Instagram API with Instagram Login** | публикация в Instagram | да |
| 5 | **TikTok Content Posting API** | публикация в TikTok | да |
| 6 | **YouTube Data API v3** | публикация в Shorts | да |
| 7 | **Cloudflare R2** (S3 API) + свой домен | публичные URL для Instagram и TikTok | да |
| 8 | Google Gemini API (Image) | только сценарий №2 (стиль по референсу) | нет, по требованию |

Свой домен нужен потому, что TikTok забирает фото только по URL **с подтверждённым владением доменом** (`PULL_FROM_URL`), а для фото-постов другого способа загрузки нет ([Photo Post](https://developers.tiktok.com/docs/en/content-posting-api-reference-photo-post)). Домен (~$10/год) подключается к R2 и подтверждается в кабинете TikTok один раз.

## 3. Какие сервисы убираем

Veo 3.1, Kling, Runway, Seedance, Hailuo, Remotion, Redis/BullMQ, ElevenLabs Forced Alignment, STT (Whisper/Scribe), Next.js-приложение, управляемый PostgreSQL. Gemini Image переходит в опциональные.

## 4. Стоимость одного поста

Допущения: одна картинка, озвучка 15–20 с (~250–350 символов), один запрос к Claude с картинкой (~3k входных токенов, ~1.5k выходных — тексты для 4 площадок).

| Статья | Бюджетно | Качественно |
|---|---|---|
| Claude (анализ + 4 текста) | Haiku 5.5: ~$0.001 | Sonnet 5.5: ~$0.02 · Opus 5.5: ~$0.04 |
| Озвучка | OpenAI `gpt-4o-mini-tts`: ⚠️ ~$0.005 | ElevenLabs: ⚠️ ~$0.03–0.07 |
| Видеообёртка (FFmpeg на своём сервере) | $0 | $0 |
| Хранилище R2 | ~$0 (в пределах бесплатных 10 ГБ) | ~$0 |
| Публикация через API соцсетей | $0 | $0 |
| **Сценарий №1, итого** | **≈ $0.01** | **≈ $0.05–0.10** |
| + Сценарий №2 (Gemini Image, 1–2 попытки) | +$0.03–0.07 (Nano Banana 2.1) | +$0.13–0.27 (Nano Banana Pro) |

Цены Claude — из справки Anthropic API (Haiku 5.5 $0.10/$0.50, Sonnet 5.5 $2/$10, Opus 5.5 $4/$20 за 1M токенов). Цены Gemini Image — [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing). ⚠️ Цены TTS — из агрегаторов; проверить на официальных сайтах.

**Постоянные расходы в месяц:** VPS ~$5–10 ⚠️, домен ~$1, подписка ElevenLabs при ее выборе ⚠️ (у ElevenLabs оплата по тарифам с лимитом символов — проверить минимальный подходящий тариф).

| Постов в месяц | Переменные (качественный вариант) | + постоянные | Итого ≈ |
|---|---|---|---|
| 30 | ~$2–3 | ~$10–30 | **$15–35** |
| 100 | ~$5–10 | ~$10–30 | **$20–40** |
| 300 | ~$15–30 | ~$15–35 | **$30–65** |

Для сравнения: в v1 качественный стек стоил ~$5 за ролик. Сейчас — примерно в 50–100 раз меньше.

## 5. Что можно публиковать напрямую (без видео)

| Площадка | Картинка напрямую? | Как | Ограничения |
|---|---|---|---|
| **Telegram** | ✅ да | `sendPhoto` + подпись до 1024 символов. Озвучку можно добавить вторым сообщением (`sendVoice`) или вместо фото отправить видео | подпись > 1024 символов → текст отдельным сообщением |
| **Instagram** | ✅ да, пост в ленту | `media` с `image_url` → `media_publish`. Только **JPEG**, до 8 МБ, **соотношение сторон от 4:5 до 1.91:1** ([IG User Media](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media/)) | вертикальная картинка 9:16 в ленту не пройдёт — её нужно аккуратно дополнить полями до 4:5 (делается автоматически) |
| **TikTok** | ✅ да, **фото-пост** | `POST /v2/post/publish/content/init/`, `media_type=PHOTO`, до 35 фото, заголовок до 90 и описание до 4000 символов, только `PULL_FROM_URL` с подтверждённым доменом ([Photo Post](https://developers.tiktok.com/docs/en/content-posting-api-reference-photo-post)) | **озвучку к фото-посту приложить нельзя.** В API есть только флаг `auto_add_music` (документация не объясняет его поведение — проверить тестом) |
| **YouTube** | ❌ нет | Shorts — это всегда видео. Посты сообщества с картинками через Data API не публикуются | нужна видеообёртка |

## 6. Где нужна видеообёртка

| Площадка | Нужна? | Решение по умолчанию |
|---|---|---|
| YouTube Shorts | **да, всегда** | картинка + голос → MP4 9:16 |
| TikTok | **если нужна озвучка** | по умолчанию **видео (картинка + голос)**, потому что голос — ваша важная часть. Переключатель «фото-пост» — для постов без озвучки |
| Instagram | по выбору | по умолчанию **пост-картинка** (самый простой и надёжный путь). Переключатель «Reels с озвучкой» — один и тот же MP4, что для TikTok/YouTube |
| Telegram | нет | фото + текст; озвучка — опционально, голосовым сообщением |

**Как выглядит видеообёртка (только FFmpeg, без AI):**
- холст 1080×1920;
- фон — та же картинка, растянутая и сильно размытая (чтобы не было чёрных полос);
- поверх — картинка целиком, по центру;
- лёгкий медленный zoom (эффект Кена Бёрнса), чтобы ролик не выглядел «застывшим»;
- звук — озвучка (+ опционально тихая фоновая музыка из вашей библиотеки);
- длительность = длине озвучки + ~1 с; H.264 + AAC, `+faststart`.

Один MP4 подходит одновременно для TikTok (3 с – 10 мин), Reels (3 с – 15 мин) и Shorts (вертикальное видео до 3 мин).

Рендер 20-секундного ролика на дешёвом VPS — секунды, стоимость — ноль.

Субтитры: в MVP не нужны, так как текст уже есть на картинке и в описании. В версии 2 — простые субтитры из таймкодов ElevenLabs.

## 7. Какие действия останутся за вами

### Один раз (настройка)
1. Перевести Instagram в профессиональный аккаунт (Creator или Business) — это бесплатно.
2. Создать Meta App, TikTok Developer App, проект в Google Cloud, бота в @BotFather; добавить бота администратором канала.
3. Подключить домен к R2 и подтвердить его в TikTok.
4. Пройти OAuth для Instagram, TikTok и YouTube (по ссылкам из бота).
5. **Сразу подать на аудиты TikTok (Direct Post) и YouTube API.**
6. Заполнить профиль проекта «Зазеркалье»: тон, ЦА, постоянные хэштеги, призыв к действию, ссылки, голос, язык.

### На каждый пост

| Шаг | Время |
|---|---|
| Отправить картинку боту (+ задание голосом или текстом при необходимости) | 3–5 с |
| Подождать (система работает, вы свободны) | ~20–60 с (не ручное время) |
| Просмотреть превью: картинка, голос, тексты | 5–10 с |
| Нажать «Опубликовать везде» | 1 с |
| **Итого ручного времени** | **≈ 10–15 с** |

### Временно, пока не пройдены аудиты
- **TikTok:** до аудита публичная публикация через API невозможна. Пост приходит **в «Входящие» TikTok как черновик** — открыть уведомление и нажать «Опубликовать»: **+10–15 с**.
- **YouTube:** до аудита видео загружаются **только как приватные**. Нужно переключить видимость в YouTube Studio: **+10 с**, либо временно отключить YouTube.

### Изредка
- Если токен отозван (смена пароля и т. п.), бот присылает «Переподключите Instagram» со ссылкой.

## 8. Как уложиться в 10–20 секунд

1. **Интерфейс — Telegram-бот.** Всё делается из одного чата, без браузера.
2. **Профиль проекта вместо повторных инструкций.** Тон, хэштеги, CTA, голос и площадки сохраняются один раз. Claude получает профиль в каждом запросе, и вам не нужно ничего писать к картинке.
3. **Один запрос к Claude → все 4 текста сразу** в строгом JSON (structured outputs). Тексты разные под каждую площадку, но генерируются за один проход.
4. **Площадки и форматы по умолчанию** задаются в профиле (например: IG — картинка, TikTok — видео, TG — фото + голос, YT — Shorts). На каждом посте их можно не трогать.
5. **Превью в одном сообщении:** альбом (картинка + видео), голосовое и тексты, свёрнутые по площадкам, плюс кнопки. Правки — кнопками: «короче», «другой CTA», «другой голос», «переписать» или ответ текстом/голосом («убери хэштег про экзамен»). Claude применяет правку и обновляет превью.
6. **Режим АВТО** (переключатель в профиле):
   - **АВТО с таймером (рекомендую):** бот присылает превью и публикует сам через N минут, если вы не нажали «Отмена». Ручное время — 0 с, страховка от ошибок AI сохраняется.
   - **Полный АВТО:** публикация сразу после генерации.
   - ⚠️ **Ограничение TikTok:** правила Direct Post требуют, чтобы пользователь **сам выбирал приватность в интерфейсе, без значения по умолчанию**, и видел превью ([Content Sharing Guidelines](https://developers.tiktok.com/docs/en/content-sharing-guidelines)). Поэтому в режиме АВТО TikTok безопаснее отправлять в черновики (`MEDIA_UPLOAD`), а прямую публикацию оставить для ручного подтверждения. Проходит ли режим АВТО аудит TikTok — выяснить при подаче.
7. **Очередь из нескольких картинок:** можно отправить боту 5 картинок подряд — он подготовит 5 постов и, по желанию, разнесёт публикации по расписанию (например, одна в день в 18:00).
8. **Итоговый отчёт** одним сообщением: ✅ Instagram [ссылка] · ✅ Telegram [ссылка] · ⏳ TikTok (черновик) · 🔒 YouTube (приватно) — и кнопка «Повторить» у упавшей площадки.

## 9. Генерация текстов и хэштегов: правила по площадкам

Claude получает картинку и профиль проекта и возвращает JSON с отдельными полями для каждой площадки:

| Площадка | Текст | Хэштеги |
|---|---|---|
| Instagram | хук в первой строке, 2–4 коротких абзаца, вопрос к аудитории, CTA («сохрани», «ответ в комментариях») | 3–5 точных + постоянные хэштеги проекта ⚠️ (актуальный лимит Instagram проверить) |
| TikTok | очень коротко, хук + вопрос; заголовок до 90 символов для фото-поста | 3–5, смесь нишевых и широких |
| Telegram | полноценный пост в стиле канала, можно с ответом под спойлером (`tg-spoiler`), без лишних хэштегов | 0–2 (для навигации по каналу) |
| YouTube | заголовок до 100 символов + описание + `#Shorts` | 3–5 ⚠️ (у YouTube есть лимит, после которого хэштеги игнорируются — проверить) |
| Озвучка | 15–25 с разговорного текста, не дублирует подпись дословно | — |

Для формата «вопрос ПДД» Claude сам распознаёт ситуацию на билете. **Правильный ответ не раскрывается в озвучке и подписи.** Он идёт в первый комментарий или под спойлер в Telegram — это поднимает вовлечённость. Для учебных материалов это важно: правильность ответа Claude нужно проверять на превью (риск №2 ниже).

## 10. Новый MVP

```
Картинка → боту
   ↓
Нормализация (Pillow)
   ↓
Claude: тема + 4 текста + хэштеги + текст озвучки (JSON)
   ↓
TTS (ElevenLabs)
   ↓
FFmpeg: видеообёртка (картинка + голос)
   ↓
Превью в боте → [Опубликовать везде]
   ↓
Telegram ✅ · Instagram ✅ · TikTok (черновик → после аудита напрямую) · YouTube (приватно → после аудита публично)
   ↓
Отчёт со ссылками + журнал
```

**Входит:** бот (только для вас), один профиль проекта, сценарий №1, превью и правка текста кнопками или ответом, смена голоса, публикация в 4 площадки, независимые повторы при ошибках, журнал, зашифрованные токены, ключи в `.env`.

**Не входит в MVP:** сценарий №2 (Gemini Image), режим АВТО, расписание, несколько проектов, субтитры, музыка, веб-панель.

**Версия 2:** сценарий №2; режим АВТО с таймером; отложенная публикация и очередь; несколько проектов/брендов; субтитры из таймкодов TTS; фоновая музыка; веб-панель с журналом и подключениями; Reels/карусели как формат Instagram; аналитика постов.

**Этапы:**
0. Аккаунты, приложения, домен, **подача аудитов** — в первый день.
1. Бот + Claude + TTS + превью (без публикации).
2. Публикация: Telegram → Instagram → YouTube → TikTok.
3. Журнал, повторы, обновление токенов.

## 11. Риски (обновлено)

1. **Аудиты TikTok и YouTube** — по-прежнему главная внешняя зависимость. Без них «везде» = Telegram + Instagram полностью, плюс TikTok и YouTube с одним ручным действием.
2. **Ошибки в контенте:** Claude может неправильно прочитать билет или неверно определить правильный ответ. Для образовательного контента это критично, поэтому режим АВТО без превью включать только после того, как вы убедитесь в качестве на десятках постов.
3. **Требования TikTok к UX** могут не совпасть с интерфейсом в Telegram-боте и режимом АВТО. На аудите может понадобиться простая веб-страница подтверждения публикации для TikTok.
4. **Instagram и вертикальные картинки:** пост в ленту принимает соотношение сторон только от 4:5 до 1.91:1. Автоматическое дополнение полями решает проблему, но может выглядеть хуже, чем Reels.
5. **Изменения API:** адаптер на каждую площадку и журнал с сырыми ответами API для быстрой диагностики.

## 12. Оценка
